# Word One

Processador de textos para Windows compatível com o Microsoft Word, com macros que você monta sem
programar.

## Baixar

**[Baixar a versão mais recente](https://github.com/rafaelleaoaq/word-one-releases/releases/latest)**
— abra a página e baixe `Word-One-Instalador-<versão>.exe`.

O instalador instala o Word One para todos os usuários do computador (pede permissão de
administrador) e pergunta se ele deve ser o programa padrão para documentos (.docx, .doc, .docm,
.dotx, .dotm, .dot, .rtf e .odt). Requisitos: Windows 10 ou 11, 64 bits.

## Atualizações

Quem já tem o Word One instalado é avisado automaticamente quando há versão nova
(*Ajuda › Verificar atualizações* para verificar na hora). O instalador baixado é conferido
(SHA-256) antes de ser aberto, e suas configurações e macros são mantidas.
